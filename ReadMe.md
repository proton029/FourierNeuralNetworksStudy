# Self Organizing maps (unsupervised)
### implemented using minisom library. Mentioned on requirements.txt. Use pip install -r requirements.txt to install all the necessary libraries

## Advantages
  - Simple
  - Interpretable visualizations
  - Relationship detection
## Disadvantages
  - Large data requirements
  - Divided clusters
  - Computational overhead

- SOMs used mainly for feature detection
- Once features are extracted we can use the new dataset with much better classification algorithms like RF
